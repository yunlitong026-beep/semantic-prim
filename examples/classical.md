# 古文文学示例（三层模型）

## 道德经：天地不仁，以万物为刍狗

表层结构（主编码，唯一）：

```
classical@1 {
  surface: [
    { s:天地, p:不仁, 以:万物, 为:刍狗 },
    { s:圣人, p:不仁, 以:百姓, 为:刍狗 }
  ],
  link: 对仗并列
}
```

本义候选 + 引申解读（外挂注释池）：

```
readings: [
  { id:1, 流派:道家, 不仁:无偏私, 译:"天地不偏爱万物，圣人也不偏爱百姓" },
  { id:2, 流派:字面, 不仁:冷酷,   译:"天地冷酷，把万物当祭品践踏" },
  { id:3, 流派:后人曲解, ... }
]
```

> 规则：主编码只存客观骨架；多种解读全外挂，不混入主编码。
