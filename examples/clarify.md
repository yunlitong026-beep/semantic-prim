# 人机置信度回询示例（外层适配器）

痛点：AI 收到自然语言提示词后自由脑补，同样的「拥抱」可能被理解成公主抱、背后环抱、普通拥抱，导致“抽卡翻车”。

## 运行

```bash
# 只看检测到的歧义（非交互）
python clarify.py --detect "黄昏柳树下，剑客看见对方，然后上前拥抱"

# 交互式逐条确认
python clarify.py
```

## 剑客示例（完整流程）

**人话输入：**

> 黄昏柳树下，剑客看见对方，然后上前拥抱

**检测结果（detect）：**

```json
[
  {
    "word": "拥抱",
    "candidates": ["普通正面拥抱", "公主抱", "从背后环抱", "侧身拥抱"],
    "codes": ["act.hug.front", "act.hug.carry", "act.hug.back", "act.hug.side"],
    "confidence": 0.25
  }
]
```

`拥抱` 置信度 0.25 < 0.7 → 回询。

**AI 提问：**

> 【语义确认】“拥抱” 有多种动作分支，请选择：
> 1. 普通正面拥抱
> 2. 公主抱
> 3. 从背后环抱
> 4. 侧身拥抱

**用户选 1 → 消歧结果（resolve）：**

```json
{
  "text": "黄昏柳树下，剑客看见对方，然后上前拥抱",
  "resolved": {
    "拥抱": {"meaning": "普通正面拥抱", "code": "act.hug.front", "confidence": 1.0}
  },
  "unresolved": []
}
```

## 说明

- 回询只针对命中歧义词的部分，不整句追问。
- `act.*` 是外层动作消歧的示意码，未并入 `film.shot` 相机 schema；AI↔AI 底层规范（spec / schema / parser）不受影响。
- 这是 V1 演示版，只覆盖少量短剧动作歧义词；完整人→编码翻译系统不在本轮范围。
